# Hunch to native Arbor parity matrix

This matrix records user-visible Hunch behavior against Arbor's node-first native app. Hunch is the interaction oracle; ArborKit, provider sessions, ArborSync, and ArborApp remain the owners. Arbor must not inherit Clamshell storage, Hunch identity, or flat-workspace assumptions.

## Current UI cluster

Implemented after Plan 017 from live inspection of Hunch `a1e8379` and Arbor's browse UI; voice/content planning was reconciled against Hunch `d13087b` and QuagmireExtras `0.2.0`:

- Hunch-derived: document-first window, hidden single-tab strip, Cmd-P sheet, footer backlinks/status, transient top banners.
- Arbor-browser-derived: containing-directory sidebar, parent navigation, active sibling treatment, compact breadcrumbs, and contextual row actions.
- Preserved Arbor boundary: every open/mutation still routes through `WorkspaceProvider` and PageID sessions; no physical workspace reads were added.
- Editing/safety pass: grouped outline/document Move To, app-owned document rhythm and feedback, focused native editor commands, inline iOS undo/redo, retryable save failure, and a save/sync status sheet.
- QuagmireExtras pass: Arbor-owned voice destinations/support roots/provider delivery, app-target shortcut phrases, injected external-link previews, and the shared transcript-polishing policy. Automated gates pass; the Plan 018 hands-on checklist remains.
