# Release 001: a Mac download that updates itself

**Why and when:** Joe wants friends to install Story on a Mac from a link on nxhx.org, and to keep getting updates without rebuilding from Xcode. Nothing in the repo builds a distributable app today. Do this after [Rename 003](../rename/003-bundle-and-keychain-identifiers.md), once Joe has the Apple items in step 1.

> **Executor instructions**: Steps 2 to 6 are repo work and need nothing from Apple. Notarizing, publishing a GitHub Release and installing on Joe's Mac each wait for Joe's go-ahead. Tagging Quagmire is Joe's step.

## Status

- **Effort**: L
- **Risk**: MEDIUM. The bundled Bun helper has never run under the hardened runtime.
- **Depends on**: Rename 003
- **Category**: release

## What exists

- One multiplatform target, `Story`, generated by XcodeGen from `swift/project.yml`. Signing is automatic for team `B7P78ULCXS`; the hardened runtime is off.
- The Mac build embeds a sync helper (`swift/project.yml`, "Build story-sync helper"): the developer's own `bun` copied to `Contents/MacOS/story-sync`, a JavaScript bundle, `@parcel/watcher` with its native `watcher.node`, a C launcher, and a launch agent plist. Each is signed without the runtime flag or a timestamp.
- `StorySyncProcessSupervisor` attaches to a running agent after checking only its service name and protocol version, so an updated app keeps using the old helper.
- `Info.plist` hard-codes version `1.0` and build `1`; `MARKETING_VERSION` in `project.yml` is unused.
- Quagmire is pinned at `0.8.0` while committed code uses API from the sibling checkout.
- The Mac has one signing identity, "Apple Development". Xcode is `Xcode-beta.app`.

## Decisions

- **Developer ID, not the Mac App Store.** The app is not sandboxed: it keeps data in `~/.story` and syncs folders the person chooses.
- **GitHub Releases on `jxe/arbor`** hosts the DMG and the appcast. nxhx.org gets a link, which Joe adds.
- **Sparkle** for updates, as a macOS-only dependency.
- **arm64 only.** The deployment target is macOS 27.
- **License**: MIT, added by the CLI publish work.

## Steps

1. **Apple account (Joe).**
   - developer.apple.com/account: membership active, no pending agreement.
   - Xcode → Settings → Accounts → Manage Certificates: add "Developer ID Application".
   - App Store Connect → Users and Access → Integrations: an API key for `notarytool`.
   - Install the release Xcode 27 and select it.
2. **Portable build.** Release Quagmire and bump both pins by the procedure in DEVELOPMENT.md. Make `Info.plist` read `$(MARKETING_VERSION)` and `$(CURRENT_PROJECT_VERSION)`. Add a copyright string and an acknowledgements file for Bun, `@parcel/watcher`, Quagmire, Yams and Sparkle.
3. **Pinned helper.** The pre-build script takes Bun at the `.bun-version` version from a checked download (checksum in the repo) for Release builds, not from `command -v bun`.
4. **Hardened runtime.** Enable it for the app. Sign `watcher.node`, `story-sync` and `story-sync-service` with `--options runtime --timestamp`, inside out. `story-sync.entitlements` starts with `com.apple.security.cs.allow-jit` alone; add `allow-unsigned-executable-memory` only if the helper fails to start. A script starts the signed helper and exercises the file watcher, and that script decides the set.
5. **Restart the helper after an update.** Stamp the app's version and build into the bundled helper, which already reports a `version` in `/v1/status`. When the supervisor finds a running agent with a different stamp, it restarts it (`launchctl kickstart -k`) and waits. Add a `StorySyncClientTests` case with a fake status. This also fixes the stale-helper attach during development.
6. **Release script**, `swift/scripts/release-mac.sh`: archive, export with Developer ID, build the DMG, notarize, staple, and write a signed appcast. Add Sparkle with `SUFeedURL` set to `https://github.com/jxe/arbor/releases/latest/download/appcast.xml`. Joe keeps the Sparkle signing key outside the repo.
7. **Clean-machine walkthrough (Joe).** On a Mac account that has never run Story: download, pass Gatekeeper, approve the login item, join from an invitation link, and pair an iPhone. Then publish a second release and confirm the update installs and the helper restarts.
8. **Publish (Joe's go-ahead).** Create the GitHub Release. Set the host's download URL so the invitation page offers it, and add the link on nxhx.org. Replace the symlink procedure in `packages/overstoryd/deploy/README.md` with the DMG install.
9. **Close out.** Record the evidence in `status.md` and delete this plan.
