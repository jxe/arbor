# Spec extensions

Proposed additions to the [Overstory spec](../../docs/overstory-spec/README.md) that nobody has
decided yet: what the spec would gain, which chapter it touches, the open question, and what is
already settled. One short file each. Nothing here is committed work. When Joe settles one, write
it into the spec (and a plan if code follows) and delete its file here.

The spec's own [deferred list](../../docs/overstory-spec/README.md#deferred) names behavior the
spec mentions but does not define; a file here may expand one of those items.

- [Pages that present other collections](pages-that-present-other-collections.md): spec 11, 02 and 06.
- [Groups that are other trees](groups-that-are-other-trees.md): spec 11 and 04.
- [Verifying the compiler as a security boundary](compiler-correctness.md): spec 07.
- [Executable data across servers](cross-server-executable-data.md): spec 07 (deferred item 2).
