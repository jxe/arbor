# Getting started

1. Read the [repository introduction and quickstarts](../../README.md) to understand the components and open or place a tree.
2. Use the [CLI reference](cli.md) for identity, daemon setup, placement, moves, and cloud sessions.
3. For development, follow [DEVELOPMENT.md](../../DEVELOPMENT.md), then the [Swift setup](../../swift/README.md) if working on the native app.

[A universal dynamic material](intro.md) explains the longer argument and intended
end state. Check [implementation status](../../status.md) for what exists today.

For deeper work, continue to the [specification walkthrough](../overstory-spec/00-walkthrough.md),
[implementing editors](../implementing-editors/README.md),
[implementing sync services](../implementing-sync-services/README.md), or
[component architecture](../architecture/README.md).
